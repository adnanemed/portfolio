# StackLab — Portfolio & Dashboard

Monorepo: `site/` (Astro, static portfolio) + `dashboard/` (Next.js admin: messages, projects, settings).

## Structure
- `site/` — public portfolio (Vercel Project 1)
- `dashboard/` — admin dashboard + public API (Vercel Project 2)
- `docs/` — content drafts, iframe verification
- `scripts/` — seed & maintenance scripts

## Setup
Copy `dashboard/.env.example` → `dashboard/.env` and fill values. Run migrations & seed from `dashboard/`.

Contact: via the site form.
